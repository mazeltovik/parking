# parking
## Для бронирования доступны даты с 01.05.2025 по 15.05.2025.
## Установка Frontend:
- выполнить установку зависимостей командой:
   ```bash
  $ npm install
  ```
- запустить сервер:
  ```bash
  $ npm run dev
  ```
## Установка Backend:
- выполнить установку зависимостей командой:
   ```bash
  $ npm install
  ```
- создать файл .env в папке backend. Скопировать в него содержимое файла .env.example
- в проекте используется PrismaORM для общения с бд Postgresql. Используйте команду, чтобы выполнить SQL миграцию:
  ```bash
    $ npx prisma migrate dev --name init
  ```
- после этого будет создана бд c именем mydb. Вы можете поменять это имя в .env файле.
- выполните скрипт заполнения бд командой:
  ```bash
    $ npm run filldb
  ```
- запустить сервер:
  ```bash
  $ npm run start:dev
  ```
